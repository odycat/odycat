# Security policy

## Reporting a vulnerability

Report vulnerabilities in OdyCAT to **<security@odycat.org>**, not in a public
issue. Reports are handled under coordinated disclosure: the publication of
a vulnerability is agreed with the reporter, and fixed vulnerabilities are
published in a security advisory once a fix is available.

## Supported versions

Security fixes are released for the latest minor release of each supported
version, until the end of the month shown.

| Version | Security fixes until |
|---|---|
| 1.1.x (latest) | 2031-11 |
