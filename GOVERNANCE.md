# Governance

OdyCAT is an open source industrial automation project. This page explains
how decisions about the library are made. Bug reports, technical ideas,
documentation and fixes are welcome.

## Who maintains OdyCAT

- **Ocean Octane S.L.U.** owns the code and the OdyCAT® trademark.
- **Yoctovision S.L.U.** publishes OdyCAT under licence from Ocean Octane:
  it publishes the releases, grants the commercial licences and handles
  support and security.

Together they are *the maintainers* on this page. Yoctovision also
contributes code, through the same process as everyone else.

## How decisions are made

- The maintainers decide what is merged, what goes into each release and
  where the project goes next. Ideas and reports inform those decisions; they
  do not commit us to a feature or a review date.
- Discuss substantial changes before starting work, so we can agree on their
  scope. We may decline contributions that do not fit the project or that we
  cannot maintain.
- Code and documentation
  contributions follow the [Contributor License Agreement](CLA.md).

How to contribute, and what makes a pull request easy to accept, is in
[CONTRIBUTING.md](CONTRIBUTING.md).

## Security reports are different

Vulnerability reports follow [SECURITY.md](SECURITY.md) and are always
handled: acknowledged, assessed and, when confirmed, fixed in a release.

## Forks

The GPL lets anyone fork OdyCAT. A fork must not use the OdyCAT name or logo
(see the Trademarks section of [LICENSING.md](LICENSING.md)): give it a name
of its own.
